# SkillWallet - AI Augmented Backend Application

SkillWallet is a digital wallet to store and verify skill certificates.

## Features
- User can upload certificates
- AI verifies certificate authenticity
- Digital wallet for skills
- Shareable portfolio link

## Tech Stack
- Python (Backend)
- AI / ML for verification
- GitHub for version control

## How to Run
python main.py
